
# SentraPulse

Smart Crowd Density Risk Prediction
and Safety Alert System

## Features
- AI People Detection
- People Counting
- Unique Person Tracking
- Crowd Flow Movement Detection
- Movement Direction Arrows
- Crowd Density Heatmap
- Congestion Monitoring
- Risk Alerts
- Analytics Dashboard

## Technologies
- Python
- YOLO
- OpenCV
- ByteTrack
- Streamlit
- Plotly

## Purpose
To improve public safety through
AI-based crowd monitoring.
